# AI Expense Categorization Trust Score

This Python script simulates an AI-powered expense categorization system. It processes expense descriptions, assigns them to predefined categories, and provides a "confidence score" and "justification" for each categorization. This demonstrates how AI systems can build trust by offering transparency into their decision-making process, a key theme of the accompanying article.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
